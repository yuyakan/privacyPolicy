# Privacy Policy

Last updated: May 9, 2026

The developer of BuzzGap ("the App") respects the privacy of its users. This Privacy Policy explains what data the App handles and how it is treated.

## 1. No Personal Information Collected

**The App does not collect any personal information from its users.**

All data created or entered by users in the App — including analyses, idea memos, brainstorm sessions, and pinned keywords — is stored only on the user's device and is never transmitted to the developer or any third party.

## 2. Data Storage

Data created in the App is stored exclusively on the user's device using Apple's SwiftData framework. The App does not perform automatic cloud sync or upload data to external servers.

## 3. AI Features

The App's AI features (insight generation, derived keyword generation, brainstorm conversation, free-text keyword suggestions) run on the user's device via Apple Intelligence. **User inputs and AI responses are never transmitted off the device.**

AI features are available only on Apple Intelligence-compatible devices (iPhone / iPad). On unsupported devices, AI features are hidden.

## 4. External APIs

To provide market analysis features, the App accesses the following public APIs. The information sent consists solely of the search keyword entered by the user and a region code; no personally identifiable information is included.

| Service | Data Sent | Purpose |
|---|---|---|
| Wikipedia (Wikimedia API) | Search keyword | Pageview counts and trending articles |
| YouTube Data API v3 (Google) | Search keyword, region code | Video counts and trending videos |
| iTunes Search API (Apple) | Search keyword, region code | App Store / Apple Books search results |
| Hacker News API (Y Combinator) | None (public article fetch only) | Technology-related trends |

Communications with these APIs are governed by the privacy policies of their respective providers.

## 5. No Advertising or Analytics

**The App does not use any advertising SDKs or analytics tools** (such as Firebase Analytics, Google Analytics, or AdMob).

No mechanisms for tracking user behavior (tracking, fingerprinting, cookies, etc.) are embedded in the App.

## 6. Crash Reports

If a crash occurs in the App, diagnostic information may be shared with the developer through Apple's standard crash reporting feature. This is an iOS-level functionality, and users can disable it under "Settings > Privacy & Security > Analytics & Improvements."

## 7. Children's Privacy

The App is not directed to children under 13. As the App does not collect personal information, no information collection from children occurs.

## 8. Data Deletion

When users uninstall the App, all data stored on the device is also deleted at the same time. Individual data items (analyses, memos, brainstorm sessions) can also be deleted from within the App.

## 9. Changes to This Policy

This Privacy Policy may be updated as the App adds features (such as advertising or analytics tools). Significant changes will be communicated via App updates and updates to this page.
