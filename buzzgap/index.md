# プライバシーポリシー

最終更新日: 2026年5月9日

BuzzGap（以下「本アプリ」といいます）の開発者は、本アプリのユーザーのプライバシーを尊重します。本ポリシーは、本アプリが取り扱うデータの種類とその扱い方を説明するものです。

## 1. 個人情報の収集について

**本アプリは、ユーザーの個人情報を一切収集しません。**

ユーザーが本アプリで作成・入力するすべてのデータ（分析結果、アイデアメモ、ブレストセッション、ピン留めしたキーワードなど）は、ユーザーの端末内にのみ保存され、開発者を含むいかなる第三者にも送信されません。

## 2. データの保存方法

本アプリで作成されたデータは、Apple の SwiftData フレームワークを使用してユーザーの端末内（ローカルストレージ）にのみ保存されます。クラウドへの自動同期や外部サーバーへのアップロードは行われません。

## 3. AI機能について

本アプリの AI 機能（インサイト生成、派生キーワード生成、ブレスト対話、自由記述からのキーワード提案）は、Apple Intelligence によりユーザーの端末上で動作します。**ユーザーの入力内容や AI の応答は端末外に送信されません。**

AI 機能は対応端末（Apple Intelligence 対応の iPhone・iPad）でのみ利用可能です。非対応端末では AI 機能は表示されません。

## 4. 外部 API の利用について

本アプリは、市場分析機能のために以下の公開 API にアクセスします。送信される情報はユーザーが入力した検索キーワードと地域コードのみで、個人を特定する情報は一切含まれません。

| サービス | 送信内容 | 用途 |
|---|---|---|
| Wikipedia (Wikimedia API) | 検索キーワード | ページビュー数・トレンド記事の取得 |
| YouTube Data API v3 (Google) | 検索キーワード、地域コード | 動画件数・トレンド動画の取得 |
| iTunes Search API (Apple) | 検索キーワード、地域コード | App Store・Apple Books 検索結果の取得 |
| Hacker News API (Y Combinator) | なし（公開記事の取得のみ） | テクノロジー系トレンドの取得 |

これらの API への通信内容は、各 API 提供者のプライバシーポリシーに従って取り扱われます。

## 5. 広告・解析ツールについて

**本アプリは、広告 SDK・アクセス解析ツール（Firebase Analytics、Google Analytics、AdMob など）を一切使用していません。**

ユーザーの行動を追跡する仕組み（トラッキング、フィンガープリンティング、Cookie 等）は組み込まれていません。

## 6. クラッシュレポート

本アプリでクラッシュが発生した場合、Apple が標準で提供するクラッシュレポート機能により、Apple 経由で診断情報が開発者に共有される場合があります。これは iOS の標準機能であり、ユーザーは「設定 > プライバシーとセキュリティ > 解析と改善」で送信を無効化できます。

## 7. 子どものプライバシー

本アプリは、13歳未満の子どもを対象としていません。本アプリは個人情報を収集しないため、子どもからの情報収集も発生しません。

## 8. データの削除

ユーザーがアプリを削除（アンインストール）すると、端末内に保存されたすべてのデータも同時に削除されます。アプリ内の各データ（分析結果、メモ、ブレストセッション）は個別に削除することも可能です。

## 9. ポリシーの変更について

本アプリの機能追加（広告の導入、解析ツールの追加など）に伴い、本ポリシーが変更される可能性があります。重要な変更がある場合は、アプリのアップデートおよび本ページの更新を通じてお知らせします。
